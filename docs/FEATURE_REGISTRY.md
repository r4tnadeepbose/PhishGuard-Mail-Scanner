## Implemented in this cycle

The following moved from planned/deferred to working code with automated coverage:

- **Investigation cases:** every scan builds `InvestigationCase` (evidence SHA-256/size, automated verdict, normalized analyzer result, timeline); analyst verdict and notes are recorded as timeline events.
- **Local case export:** `LocalCaseExportProvider` is registered in `DEFAULT_REGISTRY` and backs GUI **Save Case**, CLI `--case`, CLI `--case-dir`, and GUI **Export Cases**. External adapters remain disabled.
- **Recommendations:** context-aware advice is generated once in the scanner and reused in JSON, HTML, CLI, GUI, and case metadata.
- **Whitelist editing/validation:** exact rules can be added from the GUI while preserving both PhishGuard and ThePhish-compatible schemas; invalid files fail closed.
- **Batch depth:** CLI `--jobs` parallelism, batch HTML, one case per file, background GUI batch with progress/cancel, and double-click load-back.
- **GUI:** complete dashboard restyle (pale blue canvas, white cards, deep navy sidebar/header, navy accent, circular risk gauge) with scrollable Report tab; every control is wired to real behavior.
