 How to use PhishGuard (Help & Guide)

            

              
 Quick start (Gmail “Show original” workflow)

              
    
                
  1. Open the suspicious email in Gmail.
    2. 
                
  2. Click ⋮ (More) → Show original.
    3. 
                
  3. Click Copy to clipboard (or select all and copy the full raw message).
    4. 
                
  4. In PhishGuard, click Paste & scan (top bar) or paste into Source and click Scan source.
    5. 
                
  5. Review the verdict, risk score, findings, recommendations, observables, and security assessment. Export JSON/HTML/case if needed.
    6. 
              

            

            

              
Ways to load emails

              
    
                
  • Paste & scan: scans raw email source from clipboard.
    • 
                
  • Open file / drag & drop: load .eml, .txt, or .mail files (single scan or batch for multiple).
    • 
                
  • Samples: load or scan bundled sample emails to see how detection works.
    • 
                
  • Source tab: manually paste/edit raw source, view stats, and scan.
    • 
              

            

            

              
Understanding the results

              
    
                
  • Risk score (0–100): 0–19 Low Risk, 20–39 Suspicious, 40–69 High Risk, 70–100 Critical.
    • 
                
  • Verdict: automated triage based on explainable heuristic signals (+ optional ML signal).
    • 
                
  • SPF/DKIM/DMARC badges: parsed from headers as unverified claims (not independently validated by this tool).
    • 
                
  • Findings: evidence-based indicators with severity and score contribution. Click a finding to copy it.
    • 
                
  • Observables: extracted URLs/emails/IPs/domains (with defang/copy/whitelist actions).
    • 
                
  • Recommendations & Security assessment: suggested actions, MITRE ATT&CK/CWE hints, and triage CVSS estimate.
    • 
                
  • Details & case: metadata, evidence hash, timeline, and analyst verdict/notes (analyst decision is separate from automated verdict).
    • 
              

            

            

              
Features & tools

              
    
                
  • History: session history (persisted locally in browser), load/delete entries, filter, stats, export all.
    • 
                
  • Batch scan: scan all samples or multiple files and export batch reports.
    • 
                
  • Tools: CVSS calculator, defang/refang, Base64 encode/decode, SHA-256 hashing, quick IOC extraction.
    • 
                
  • Whitelist: refresh/validate and add exact observables (reduces noise for known-safe items; use carefully).
    • 
                
  • Exports: JSON/HTML scan reports, case JSON, batch JSON/HTML, Markdown/summary copy.
    • 
                
  • Rescan: re-run analysis on the current source (useful after toggling ML or updating input).
    • 
              

            

            

              
Keyboard shortcuts

              
    
                
  • Ctrl/Cmd + Enter: Scan current source
    • 
                
  • Ctrl/Cmd + O: Open file picker
    • 
                
  • Ctrl/Cmd + B: Scan all samples (batch)
    • 
                
  • Ctrl/Cmd + S: Save/export current case JSON
    • 
                
  • Esc: Clear status message
    • 
              

            

            

              
Safety & limitations (important)

              
    
                
  • Local/offline-first: analysis runs locally; no attachments are executed and links are not auto-opened.
    • 
                
  • Not foolproof: phishing detection can have false positives/negatives. Compromised legitimate accounts and novel attacks may evade heuristics.
    • 
                
  • Auth headers are claims: SPF/DKIM/DMARC shown in headers are not cryptographically verified by this app.
    • 
                
  • Verify independently: for suspicious messages, confirm via official channels/out-of-band before taking action.
    • 
              

            

            

              
Troubleshooting

              
    
                
  • If Paste & scan can’t read clipboard, your browser may block clipboard access — paste into Source and click Scan source.
    • 
                
  • Ensure you copied the full raw source (“Show original”), not just rendered text, for best header/auth analysis.
    • 
                
  • If a sample/scan fails, check Activity for errors and confirm the server is running (python server.py / run.py).
    •
